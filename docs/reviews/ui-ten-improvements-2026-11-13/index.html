Email, Continue and the privacy notice precede a Read the welcome disclosure. Expanding it preserves the entered email.

F5 · Implemented

Search and folder browsing use a compact welcome disclosure, fewer repeated headings and direct results. The first result in the 320 px search fixture starts at y=312. Query and folder context survive returning from a document.

F6 · Implemented

Protected sharing-link drafts

Escape, Close and Cancel ask before discarding changes. Keep editing retains the draft. Page reload warns; drafts do not carry to another link or get stored in browser storage.

F7 · Implemented

Explicit preview dimensions

Fit to panel adapts to available space. Phone renders a 360 px sample; Desktop renders a 1280 px sample. Both show scale and provide Actual size. The desktop sample has three pinned columns even when the owner uses a phone.

F8 · Implemented

Compact PDF search

Search replaces the second mobile toolbar row. At 320/390 × 500 the toolbar is 115 px high, compared with about 174 px in the audit. Page navigation, zoom and thumbnails remain available through Reader options.

F9 · Implemented

Document tools before setup summaries

Search, Folder and Upload precede a collapsible mobile pinned summary. Server status is consolidated, urgent disk warnings remain visible and backup guidance can be expanded. The room menu is labelled Options.

F10 · Implemented

Mobile protection context

Sharing rows retain email verification, NDA, password and watermark facts. Protected and open-email links can be compared before copying; text wraps at 320 px.
