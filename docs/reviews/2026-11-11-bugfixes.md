# Review and 30 bug fixes

Reviewed on 11 November 2026 against the existing working tree. The review used a source snapshot,
disposable SQLite databases, disk files and real operation and route implementations. Existing
uncommitted work, including activity-reporting changes made during the review, was preserved.

The initial reproduction run had 31 failing cases for the 30 distinct bugs below: member and investor
upload expiry were exercised separately. Two PDF controls already passed and were excluded from the
bug count. Additional permission, credential, archive and transport checks cover the resulting fixes.

| #   | Reproduced failure                                                                                                                  | Result after the fix                                                                                                                              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | A cached member role could authorize an operation after demotion or removal; asynchronous changes could outlive API-key revocation. | Execution reloads membership and key state; asynchronous credential, link, upload, branding and storage changes recheck before saving.            |
| 2   | A code for a gate's previous email could verify its replacement email.                                                              | Code checking requires the gate's current email and a live gate.                                                                                  |
| 3   | Received uploads could be finalized after expiry, for members and investors.                                                        | Both paths check expiry before work and when claiming the upload.                                                                                 |
| 4   | A final checksum could override a different checksum supplied when creating an upload.                                              | Both supplied checksums must match the received bytes.                                                                                            |
| 5   | Downloads starting at a nonzero Range offset were omitted from activity.                                                            | Successful partial downloads are recorded with the existing deduplication window.                                                                 |
| 6   | Versions-read reports included reads outside the selected link or time.                                                             | Version queries apply the activity scope and time bounds.                                                                                         |
| 7   | Multiple sessions from one investor inflated video viewer counts.                                                                   | Each video tenth counts distinct investors.                                                                                                       |
| 8   | A video's current heatmap included watches of older versions.                                                                       | The heatmap reads only the current version.                                                                                                       |
| 9   | Filtered investor reports displayed custom answers from a different link or period.                                                 | The answer lookup uses the report's scope and time bounds.                                                                                        |
| 10  | The current-viewer section ignored activity filters.                                                                                | It applies the same link, group and time selection.                                                                                               |
| 11  | Revoked, expired or otherwise disallowed sessions appeared as current viewers.                                                      | Passive session validation removes viewers who no longer satisfy access or NDA rules.                                                             |
| 12  | Stored video coverage could exceed the reading time the server granted.                                                             | Only newly covered ranges within the granted budget are stored.                                                                                   |
| 13  | Merging video ranges counted gaps of up to one second as watched.                                                                   | Only overlapping or touching ranges merge.                                                                                                        |
| 14  | Video beacons could create video reads and read-past events for PDFs.                                                               | Tracking accepts only the current file's media type; image pages are limited to page one.                                                         |
| 15  | Domain normalization silently dropped URL paths, queries and fragments.                                                             | Those inputs are rejected before domain conversion; DNS labels are validated.                                                                     |
| 16  | Email normalization accepted recipient-list syntax and control characters.                                                          | The local part must be one bounded address; internationalized domains still work.                                                                 |
| 17  | OpenAPI discarded alternative top-level request bodies, hiding email-provider inputs from generated clients.                        | Request alternatives survive generation and the CLI discovers their fields.                                                                       |
| 18  | A file request kept accepting files above a reduced install upload limit.                                                           | New requested uploads use the lower of the request and current install limits.                                                                    |
| 19  | File-request emails still went to investors whose links had been revoked or whose access was blocked.                               | Recipients need a currently active, allowed link and receive one email each.                                                                      |
| 20  | Supplying a link and group filter ignored the group.                                                                                | Both filters select their intersection.                                                                                                           |
| 21  | Rounding many page allocations could exceed the granted session time.                                                               | Each allocation is bounded by the remaining grant.                                                                                                |
| 22  | Read-past recognition ignored page time split across an investor's sessions.                                                        | Time is summed per investor, page and file version before applying the threshold.                                                                 |
| 23  | Expired pending exports exhausted the build-slot limit.                                                                             | Build limits count unexpired work; expired zip jobs do not start.                                                                                 |
| 24  | A missing zip source emitted an unhandled stream error and terminated the worker process.                                           | Shared zip writing handles source, output and finalization failures, cleans partial output and lets the worker retry; archives use the same path. |
| 25  | An unpaired Unicode surrogate in an accepted filename broke downloads.                                                              | Download headers replace malformed Unicode before encoding the filename.                                                                          |
| 26  | HEAD requests generated download activity and email notices.                                                                        | Only successful GET responses count; unsatisfiable ranges also stay out of activity.                                                              |
| 27  | Malformed admin JSON became an empty input and could execute an operation.                                                          | Invalid or non-object JSON receives 400 before execution.                                                                                         |
| 28  | A session ended while a beacon body arrived could still write reading activity.                                                     | The route revalidates access after receiving the body.                                                                                            |
| 29  | An in-flight invite resend recreated a password token after cancellation.                                                           | Saving requires the same pending invite and active member; rejected work discards its new token.                                                  |
| 30  | In-flight API-key creation left a new credential after member removal.                                                              | The result is reauthorized and a rejected new key is deleted.                                                                                     |

The CLI also preserves numeric text for nullable string fields, such as link passwords, instead of
coercing it into a number. Generated build artifacts are excluded from the Docker context.

## Verification

- Node 24.21.0: 42 disposable database, disk, operation and route checks passed, including both
  upload-expiry paths, verification races, authorization changes during password hashing, private
  conversations, inherited group access, current allow/block rules and cross-origin rejection.
- Healthy zip contents were compared with their source bytes. Every entry of a frozen archive was
  checked against `manifest.sha256`; the zip's own CRC checks passed too.
- All 12 production REST, MCP and CLI smoke checks passed, exercising authentication, generated request alternatives,
  uploads and live authorization changes. The old CLI's numeric-password failure was reproduced
  against the same production server before checking the correction.
- `npm run lint` passed with no diagnostics or code comments. `npm run build`, CLI catalog drift
  checks, shell syntax/ShellCheck and the Docker image build passed.
- A redacted secret scan of the current tracked and untracked source files found no leaks.

Local evidence is kept under `artifacts/reviews/2026-11-11-bugfixes/`. Throwaway scripts are removed
from the working tree. No test suite, dependency, database schema or migration was added. The review
does not constitute a release, deployment, fresh-VPS install or S3 replication/restore drill.
